# Maa-PCR

Windows x64 的 PCR 国服自动化。提供“日常&扫荡”“黎明界bot”和“公会战”三个独立配置，使用 MaaFramework 识别页面和执行输入。

## 当前状态

R74 改用“首领”铭牌定位黎明界 Boss，减少立绘遮挡平台的影响。客户端启动兼容缺少 `monkey` 的镜像；停止任务后等待执行进程退出，资源清理期间按钮显示“处理中…”并禁用。Logo 改为透明背景。稳定版和历史变更见[下载页](https://github.com/shiwandehongbai/Maa-PCR/releases/latest)和[更新记录](CHANGELOG.md)。

R73 的页面切换、角色列表和反馈入口修复继续保留：黎明界会等待数据连接完成，再确认战斗或页面切换结果；滚动到列表边缘时核对完整可见的角色，并处理最后一帧；日志导出窗口提供 GitHub 和邮件反馈入口。

R72 已在本机完整通关黎明界，验证了 300 币和 600 币的刷新扣款、Boss 连续领奖和多队编组。公会战本版只验证了账号资料读取，当前游戏内容版本仍缺少公会战校准。黎明界功能范围见[上游功能对照](docs/LABYRINTH_UPSTREAM_PARITY.md)。

公会战支持作业整理、账号与五人核对、三刀计划、全自有无轴模拟、固定 2 倍速普通挑战及单条补偿。保留 SET／AUTO／速度继承，开场暂停后只调整与作业不同的项。D5→D4→D1 三队模拟通过，2026-10-29 三场普通挑战分别通过正常 GUI 全程自动执行；第二刀后因期限临近停止，重新运行后按原账继续第三刀，前两刀未重打。同一 Owner 连续三刀仍未实证。借人、战中秒数轴、4 倍速和多条补偿尚未开放，见[公会战分项验收](docs/CLAN_ACCEPTANCE.md)。

日常、黎明界和公会战共用实时日志布局，各保留最近 500 行显示，按功能与运行编号独立保存。每功能用户诊断缓存和导出 ZIP 含截图，上限均为 16 MiB；业务账本、未决记录和原始开发证据不参与轮换。报错后可准备日志包，检查并移除截图，再打开预填 GitHub Issue 或邮件（a877236828@gmail.com），由玩家添加附件后提交。软件打开反馈窗口只表示已准备反馈。

任务结束、失败或停止后，确认执行资源释放再允许切换功能；释放未确认时显示原因和重启提示。修复旧运行延迟通知覆盖新运行状态的问题，以及启动和结束设置保存、快捷方式参数与工作目录，支持系统代码页之外的 Unicode 快捷方式路径。PCR 模式保留单功能自动启动，隐藏无效的跨功能批量启动区域。

黎明界兼容已有导航记录，按操作语义核对局号和服务器状态，保留未知结果且不重发。日志导出只生成用户选定的一个 ZIP，导出期间禁止重复触发。连接与首帧准备最多等待 30 秒；停止或超时后，界面结束等待，旧原生调用和资源仍未回收时继续禁止重连、切换配置和更新。真实 ADB 卡死尚未实测，界面取消不代表原生调用已经终止。

既有功能和保护继续保留。R53 的局部性能证据见[性能测量](docs/R53_PERFORMANCE.md)，整体日常和黎明界整链提速尚未实测，不公布整链百分比。版本含义、源码入口及检查命令见[开发指南](docs/DEVELOPMENT.md)。验收须与 `delivery/acceptance.json` 的修订号、源码和载荷同时匹配；旧结果不能代替最终包验证。

日常只运行玩家选定的已支持项目，不包括自动购买、付费扭蛋、重置或推图；`daily_complete=false` 不会因版本发布改成“覆盖全游戏”。黎明界保留完整功能并标为测试版，继承 R38 难度5真实通关证据；同批双成功及随机分支缺口见 [验收范围](docs/RELEASE_STATUS.md)。

黎明界的“保留旧局”默认关闭。再次开始时，程序先核对旧局；旧局仍在进行就撤退，确认结束后新开。需要保留时打开开关，选择会自动保存。无法安全续跑时会提示手动处理；未知撤退不会重复发送。实机断网和强退后的恢复尚未验收。

## 安装与更新

首次安装或离线更新所需的 ZIP 均在 [稳定版下载页](https://github.com/shiwandehongbai/Maa-PCR/releases/latest)。

- **首次安装**时，将完整运行包 `Maa-PCR-v0.1.27-win-x64.zip` 解压到新的可写目录，启动 `MFAAvalonia.exe`，再配置模拟器和任务。无需安装系统 Python。
- **在线更新**时，软件默认在启动后检查稳定版，也可以手动点击“检查更新”。发现 R74 后，点击“下载并安装”。正式 R73（v0.1.26）使用增量补丁，更早的受支持版本使用完整运行包。
- **离线更新**时，正式 R73 导入 `Maa-PCR-R73-to-R74.patch.zip`。R39 至 R72 的正式版本导入完整运行包 `Maa-PCR-v0.1.27-win-x64.zip`。请从软件的更新入口导入，不要解压覆盖原安装目录。

等任务结束后再安装更新。维护器会保留账号、设置、任务顺序、评分、账本（包括结果未知的记录）及计数。更新后只重启软件，任务需要手动启动。

仍在使用 R38 的用户，先运行 R38→R39 引导包内的 `first-update.bat`，再从软件内更新。测试候选须由维护器核对清单。详见[更新与故障恢复](docs/UPDATES.md)和 [R54→R52 专用转换说明](docs/R54_TO_R52.md)。

## 开发

开发环境、公开回归和 GUI 检查统一见 [开发指南](docs/DEVELOPMENT.md)。发行构建入口为 `scripts/build_release.py`，使用 `--help` 查看固定依赖、工具和构建参数；构建产物和日志只写 `.runtime`。

发布构建使用 `Release` 配置和 NuGet `--locked-mode`，提交的 `packages.lock.json` 仅对应 Release。Debug 含额外诊断依赖，开发时须使用独立的 Debug 锁文件；不要用 Debug restore 覆写发布锁。

源码、运行包、补丁和更新索引必须来自同一发布版本。历史原生二进制不宣称逐字节可复现。[贡献与反馈](CONTRIBUTING.md) · [黎明界集成](docs/LABYRINTH_INTEGRATION.md) · [来源和许可证](docs/SOURCE_AND_LICENSES.md)。

黎明界玩家 ID、用户名和密码使用当前 Windows 用户的 DPAPI 加密保存在本机，界面默认隐藏这些信息。B 服首次登录并核对玩家 ID 后，程序也会加密保存 SDK 令牌，供黎明界和公会战账号资料同步复用。服务器要求验证码时，请在软件的“人工安全验证”窗口完成验证。缺少 WebView2 或窗口打开失败时，改用系统浏览器。详见[登录复用说明](docs/SDK_SESSION_CACHE.md)。

请勿提交配置、账本、原始日志、截图或凭据。项目使用多种第三方许可证，根 MIT 不覆盖全部组件。
