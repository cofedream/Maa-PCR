# R53 综合提速候选验收范围

本候选保留旧 R53 活动短列表修正，正式安装仍为 R52。未自动安装、未启动任务或重放游戏消耗，未正式发布。构建身份由程序清单和外层交付回执绑定。

## 收尾容错及后续提速

本轮以 R53-67923e1a61e4 为基线。计时收尾的两处普通异常现在只标记统计不完整，不改变业务终态，也不跳过原生 Stop、监听器关闭和客户端清理。一次性及持续故障均有回归；KeyboardInterrupt 和异步取消仍按原规则传播。

活动列表和深渊报价只在当前回调缓存相对行 ROI 的配置副本，每行再复制并平移。下一次回调重新读取配置，OCR、动态金额和最终动作帧不缓存。四场景配置查询由 9→3、12→4、18→6、9→3，每回调节省约 0.5～1.1 ms；测试包含真实 Maa 配置读取和确定性 OCR 替身，这不是完整 OCR 或整链耗时。

头像 fine 只计算原流程已经选出的候选。coarse、属性与 roster 筛选、稳定排序、上限、变体合并、rival 和阈值保持；默认完整评分接口仍返回全部分数。七场景各预热 5 对、交替 20 对，完整返回与实际消费分数字节相同，P95 均通过。完整 Python 回调 P50：开局选角 462.13→382.58 ms、Boss 选角 554.42→507.46 ms、加入头像 63.33→49.84 ms；三头像奖励核心 67.63→46.32 ms。这些使用保存图及确定性识别替身，不包含真实设备截图或游戏等待。

稀疏取样仅冷评分有优势，热六次匹配 P50 102.69→103.91 ms、P95 118.78→138.67 ms，本轮不集成。继续保留当前回调共享 RGB/亮度与每个裁剪的梯度边界，不能只凭冷路径收益改变生产实现。

回执元数据取图和报价同帧合并仍为独立实验。固定 SDK 的公开 Python 接口没有省略图片的选项，远程传输也不会因此省掉；同帧报价还需新的真实回执协议，不能伪造旧顶层节点。生产 SDK、报价回执、消费检查和 DebugMode 保持。

本轮的完整回调性能、代码复查、公开回归、随包 OCR 和精确升级证据见外层包。本轮新增收益不能与前轮截图、预览或等待节省直接相加，整链比例仍待可比的自然运行。

## 已实施

- 110 个明确的无输入节点显式零前后延迟；导航和返家两处固定 1 秒经保存页转场、空白和遮挡回放后移除。50 个输入节点与基线相同。后继页面就绪、输入后的转场等待、拖动和稳定窗保持。
- 次数调整使用本步真实 FitUpdatedRead，保留初始、全部调整后及恢复后独立读数。奖励关闭使用 CloseStart 已确认最终状态和缓存帧。确认页只在单次回调缓存相对 ROI。
- 角色识别按当前数组身份共享 int64 RGB/亮度，完整候选和每个裁剪的梯度不变。地图保留全部场景规则及五槽模板，仅跳过不存在槽的数字 OCR；未知不补零。
- 标准 Encode | RawWithGzip 在连接阶段测速。GUI 两条截图命令绑定相同物理显示器，输入保持逻辑显示器；默认屏兼容行为保留。CLI 显式显示器语义保持，黎明界仍为默认屏范围。
- 计时按日志文件身份与偏移处理轮转，不重复计数；未观察到截图耗时标量时保持 None。叶子识别、完整任务等待、业务阶段不能相加。性能报告、统计失败或缺失不产生结算、恢复、重试授权。
- 日常任务运行或原生停止尚未结束时，自动预览读取主控制器的业务缓存，不新增预览抓屏。缓存展示最多每秒 5 次，用户更低的刷新设置保持。空闲后恢复原截图预览；已提交的预览任务仍按真实终态处理。缓存显示不清除截图失败计数，缺图不伪装成功。连接首帧、手动截图、业务新鲜帧、显示绑定检查和调试取证保持。黎明界使用独立控制器，本轮保留其原预览行为。

当前日志缺少每次外部抓屏的调用者标记，无法把全部外部截图都归给预览，也不能将截图累计耗时直接从总耗时中扣除。本次不再叠加公布一个未经自然运行验证的整链比例。

## 截图与调试实验边界

设备采样单独使用禁用输入控制器，连接/预热/持续帧分开计时；设备、目标显示和缺项以外层采样报告为准。MuMu 的逻辑非默认显示绑定不构成黎明界默认屏验收。没有雷电独立样本时列为未测，不把同模拟器的两个 ADB 地址计为两台设备。

独立 DebugMode 开关实验采用保存画面、隔离进程、5 次预热及 20 对交替样本。默认读取链 P50 216.26→107.71ms，JSON、通知配对及输入资格一致，但关闭后 raw/draw 和失败原始帧消失。生产 DebugMode 与缓存取证保持；实验收益不计入本候选。OpenCV PNG 微测 P50 13.95ms 也不是原生编码的独立测量。

v2 截图性能 sidecar 仅从本次连接日志观察实际后端，请求集合 6 不表示实际后端。报告记录配置、显示依据、清单和日志指纹；缺失、歧义或写入失败只影响性能证据。报告窗口为 connection_only，不能证明整个游戏运行期间后端永久不变。Maa 5.13 原有内部截图重试/恢复未修改；应用层在 SDK 对外报告失败后停止，不增加切换、重连或输入重发。MuMu EmulatorExtras 正式入口仍阻断。
