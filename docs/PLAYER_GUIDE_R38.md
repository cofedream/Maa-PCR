# MAA PCR R38 · 双配置使用说明

启动播放器后，顶部提供“日常&扫荡”和“黎明界bot”，分别保存任务和参数。首次选择黎明界时复制日常设备选择，之后分别调整。黎明界运行期间界面显示阶段和完成次数；Stop完成后恢复编辑。

## 黎明界bot

选择设备、目标公会、难度及目标次数。默认按通关次数完成目标，也可选择按尝试次数；只有真实通关或已确认战败耗尽后的终态计入尝试，未知结果不计。匹配且尚未推进的既有开局可经实际协议与页面读回复用；已推进或不匹配的旧局实际撤退后创建新局。仅在无局内执行的ready阶段恢复同一配置批次，不能自动恢复任意半途角色、遗物或计数。

刷开局默认关闭；开启后按路线/Boss条件刷取，每局最多100次或30分钟，任一达到停止。默认允许本局货币购买遗物，新增配置使用上游商店刷新默认开启、从区域5开始；旧配置中明确保存的关闭保持。高级策略包含19项参数：玩家评分权重、同属性加成、重复职能及物法混编扣分、有效角色加分、Boss伤害体系偏好、单队失败转多队及重试次数、连续三败重开、基础层数截止区域与目标、追弱体最低层数与容差、主追印记优先级、商店刷新及起始区域、普通/EX胜率、各公会开局三人候选。保存后重开沿用，当前运行使用启动时快照。

按固定上游安全点推进已拥有的召唤/奖励/最终动画，后继页面和实际角色、奖励、通关仍分别读回确认。事件选择已发送后仍在同一事件页满6秒时，排除该选项再选不同选项；其它已发送动作结果未知仍停止，不自动重发。实际战败按配置有界重试并排除失败阵容，达到条件可从单队Boss切换多队；耗尽后记录真实失败、撤退，并按批次剩余目标继续。

展开“协议辅助 · 国服 B 服账号”，填写游戏玩家ID、B服账号和密码后Start，极验由用户手动完成。账号、密码和SDK票据仅当前会话内存持有，不进入配置或交付包，同批复用登录。PCR每天北京时间04:00刷新日期；需要重新登录属于正常刷新。

## 保留数据的升级

从R37活动修复升级使用精确37→38补丁；其他版本须各自匹配清单。升级前关闭播放器与任务，由安装目录外的Python执行随包维护脚本。升级保留设置、任务顺序、全部日志和账本；完整包用于新的目录，不用解压覆盖替代维护器。

R38承接R36的19项普通导航OCR设置与R37活动过期修复，其它既有业务阈值和等待保持。最终运行、匹配源码及验收说明由交付清单绑定；本文件中的功能说明不代替逐项实机验收记录。
