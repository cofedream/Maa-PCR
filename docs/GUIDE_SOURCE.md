# 攻略原图获取与逐人确认

本功能把公开攻略整理成原面板可以核对的材料。账号仍从本机快照复用，游戏仍由原 Start／Owner／Maa／Journal 执行；本轮新增材料只用于离线整理，没有增加游戏执行入口。

## 复用本机原图

在独立 checkout 执行。下面使用已经取得的 8-8 表格原图，输出目录必须尚不存在：

```powershell
& .\.runtime\guide-acquisition-20261018\candidate\player\runtime\python\python.exe -X utf8 -B scripts\prepare-guide-source.py `
  --image .runtime/guide-fire86-control-20261019/author-fire6-8-rows6-10.png `
  --source-url 'https://docs.qq.com/sheet/DQnFpRmNYWVVuWWFk?tab=m70z7u' `
  --stage '红焰深域 8-8' --crop 885 402 385 74 `
  --locator '墨夕公开表格火6~8图，8-8第一队' `
  --retrieved-on 2026-10-19 --output .runtime/guide-source-88-manual
```

原图可以是 PNG 或 JPEG，按内容识别格式。取得日期填写原件实际取得日期；复用时不更新。脚本保留 `original-image` 原字节、`row.png` 行图、`source-identity.json` 核对文件。该文件不含账号资料和人工确认。

当前布局只校准了红焰第八图的五人横排：行图归一为 344×66。裁切位置必须依据原图指定。其他布局、重复角色、非火属性、损坏或过大图片会停止，不自动猜切行。

## 获取 B 站公开材料

同一脚本也接受 `--video-url 'https://www.bilibili.com/video/BV号/?p=分P' --at 秒数`，替代 `--image` 和 `--source-url`；仍须填写关卡、裁切、定位、取得日期及新输出目录。

脚本校验返回的 BV、分 P 和 CID，保留公开元数据、视频、原帧及摘要。仅处理可直接取得的单文件视频；不接受合集或短链接，不使用浏览器凭据。访问失败、视频过大或时间点无效时保留已取得材料和失败记录，不生成可确认结果。

视频中的装备页面不是五人攻略横排，不能用同一裁切位置识别。应保留装备原帧作参考，不把装备图标或旧队伍自动转换为当前队伍要求。

## 在原面板操作

1. 导入攻略草稿或填写来源、区服、关卡、实际取得日期。来源必须与原图一致；表格截图使用表格链接，视频说明可保留在文字材料中。
2. 点击“导入原图核对文件”，选择 `source-identity.json`。来源、日期、关卡、编号、目录形态不对应时拒绝导入，保留原资料。
3. 尚未填五人时，使用“按原图生成五人”，再补原文确实给出的星级、练度和 SET 标记。保留 O／⚪／X 原文，不清楚的项继续待确认。
4. 并排查看原图与目录头像，逐人确认角色编号和形态。新导入材料的五人都要核对，分数高也不自动代替确认；原识别分数和低分证据保留。
5. 保存后可重开查看。编辑来源、关卡、原图、编号、形态、定位或文字材料后，原确认失效。导出草稿及攻略库条目清除确认和账号资料，载入后重新确认。

原图确认是资料核对，不是开战授权。新导入材料即使离线对照完整，仍不能从本面板开战；现场校准与具体目标授权另行处理。旧已校准材料和历史账本保持原义。
