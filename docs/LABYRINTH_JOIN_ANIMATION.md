# 黎明界角色加入动画：本地配置与游戏内回退

## 背景

「角色加入动画」开着时，选角奖励选完还要先点掉角色登场动画，才能读到「角色加入」页。一次慢速观察约 2 秒、一次带守卫的推进点击约 4 秒（全页场景识别），旧的 12 秒读回预算会被动画阶段耗尽：诊断局 `acbd272e`（v0.2.2）在最后一次跳过确认后 1–2 秒就停止，报 `role_reward_readback_unknown`，实际「角色加入」页还没被读到。角色获得阶段的读回预算沿用上游 #49 的 45 秒邀请过渡预算（`opening.py` 的 `INVITATION_TRANSITION_TIMEOUT_SECONDS`），「角色加入」页与角色身份仍逐项读回。

更根本的做法是关掉动画：

1. 客户端本地 `SharedPreferences` 路径：[animation_setting.py](../src/pcr_maa/labyrinth/animation_setting.py) 在启动游戏前读取；确认是「播放」且设备有 ADB root 时改为「不播放」。键值随客户端版本变化（2026-11-17 校准的是 B服 11.7.2），无法识别时不改写、只提示并继续，本次运行仍会播放动画。
2. 游戏内界面回退：[animation_ui.py](../src/pcr_maa/labyrinth/animation_ui.py) 在进入黎明界地图后，用「菜单 → 设定」把同一选项设为「不播放」。

## 触发条件

- 触发状态（`animation_ui.needs_ui_fallback`）：`no_root`、`unknown`、`write_failed`、`error`、`stop_unverified`、`stop_failed`，即本地配置路径没能确认「不播放」。
- 不触发：`already_off`、`fixed`（已确认关闭）、`stopped`（任务正在停止）、`adb_missing`（连 Maa 设备操作都没有）、状态未知（旧调用方未提供）。
- 时机：刷完开局、初始三人邀请完成并关闭「角色加入」页、进入黎明界地图（handoff 后第一张确认地图）时；在路线执行前执行一次。
- 同一批次的后续局沿用已确认状态，不再重复进入设置页；跨批次会重新检查（客户端设置本身会保存）。
- 已确认「不播放」时（本地配置 `already_off` / `fixed`，或进地图界面读回后），角色获得等待不再对 `unknown` 过渡帧做推进点击；只有实际识别到角色动画帧才恢复点击，避免玩家中途改回「播放」时卡住。

## 界面流程

地图（已确认）→ 点右上角「菜单」→ 等待菜单面板 → 点「设定」→ 等待设定页 → 读取「角色加入动画」当前状态：

- 已是「不播放」：直接关闭，返回地图；
- 是「播放」：点切换，然后在**新帧**读回「不播放」，再关闭设定、关闭菜单，返回地图；
- 其他状态（读不到/同时命中/切换后仍不是「不播放」）：停止本批次，不继续盲操作。

最后必须重新读到确认过的地图页才继续路线；关闭设定后若直接回到地图，则跳过关闭菜单一步。

## 安全边界

- 每个页面由同一帧上完整的、无动作的锚点集合识别；点击节点是「页面守卫 And 控件」，帧变化只会得到「已证明未发送的输入」，不会盲点。
- 「菜单」打开节点使用同帧自定义守卫：设置页或右侧菜单面板已经展开时守卫不命中，避免把刚打开的菜单又点关。
- 切换后必须在新帧读回「不播放」才离开设置页。
- 只能从已确认地图开始、并回到已确认地图；菜单/设置页仍可识别时，用校准的关闭节点退出后再继续。
- 输入结果未知、或页面无法识别时停止批次；不重试、不猜测、不把未知输入当成功。
- 未校准时 `available()` 为 False：不注册节点、不产生任何输入，只打一行日志，运行继续使用上游的邀请过渡读回预算（保留给未来客户端改版重新校准）。

## 校准（2026-11-21 实机完成）

同一模拟器（MuMu 12，CN B 服客户端，1280×720）取样，帧保存在本地私有目录 `.runtime/join-animation-calibration/`（不随源码分发）：

| 画面 | 关键锚点 | 取值 |
| --- | --- | --- |
| 地图 | 现有 `LabyMapObserved`；右上角菜单 OCR `^菜单$` | 点击点 `[1217,71]` |
| 「菜单」面板 | 标题「详情」（OCR 可读为 `?详情`，用 `^.{0,2}详情$`）、「指南」「帮助」、入口「设定」 | 面板 ROI 见 `CALIBRATION`；入口点击点 `[1093,111]` |
| 「设定」弹窗 | 标题「设定」、「设定是否播放角色加入动画。」、「播放」「不播放」、「关闭」 | 关闭按钮中心 `[637,494]` |
| 选项状态 | 选中的蓝色圆点模板 `labyrinth/join_animation/radio_selected.png`，左侧 ROI = 播放、右侧 ROI = 不播放 | 模板为 27×27 裁剪，两侧分别做 TemplateMatch `.9` |
| 切换用点击点 | 右侧单选圆点中心 | `[690,380]` |

要点：面板打开时地图仍可见，现有 `LabyMapObserved` 也会命中，所以页面判定顺序固定为「设定 > 菜单 > 地图」；日期变更与断线使用本模块自带的 OCR 锚点，不依赖会话期才安装的节点。`SOURCE_NOTICE.json` 已登记新模板的来源、裁剪坐标与 SHA-256。

取样时同时确认了返回路径：设置「关闭」回到菜单面板，再点右上角「菜单」关闭面板回到地图；同一次点击在面板开/关两种状态下都有效。

## 实机验证（2026-11-21）

用安装内的 Maa 资源 + 真实 ADB 控制器、仅经由游戏自身的菜单/设置页做端到端运行（不涉及协议、账号或战斗操作）：

- 状态已是「不播放」：`already_off`，4 次输入（菜单→设定→关闭→菜单），9.2 秒，最终回到地图；
- 先把状态改为「播放」再运行：`toggled`，5 次输入（多一次切换），9.2 秒，新帧读回「不播放」后返回地图；
- 结束后重新打开设定页核对，确认为「不播放」，游戏留在黎明界地图、面板关闭；
- 运行期间日志中的操作均以 `join_animation_*` 写入账本，含 `enter_id` 与 `phase`；
- **真实新开局验证**：把动画设为「播放」，从黎明界主页走游戏 UI 出发（美食殿堂、难度 5），选 3 人邀请并跳过三段加入动画进入地图（区域 1/5、角色 3、遗物 2）；在该地图上执行同一回退流程，读到「播放」→切换→新帧读回「不播放」→关闭设置/面板→返回地图，5 次输入全部 ACK，**11.3 秒**；随后重新打开设定页核对为「不播放」。

该链路已在真实任务中自动触发：进入地图后自动关闭动画，后续角色奖励沿用同一状态；用户实测一轮通过，第二轮手动停止。
