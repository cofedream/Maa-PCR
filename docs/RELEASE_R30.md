# R30：礼物箱体力暂缓与后续任务衔接

礼物箱已领取其他道具后，可能只剩暂不可收取的体力（例如界面勾选了除体力外收取），“全部收取”按钮为不可用状态。R29只有“可领取”和“空箱”两个分支，因此误报Post-claim state unknown并停止其后的深域、高难、困难及补领。

已收取的其他礼物仍以原领取结果为准；体力礼物保留在箱内，不伪造全部收取或空箱。没有可验证的领取结果、未知弹窗、错误页面、取消/返回主页失败及Stop撤权仍正常停止。此修复针对本次保存帧确认的礼物箱状态，不把所有异常弹窗一概取消。
