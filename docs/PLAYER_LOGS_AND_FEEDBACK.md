# 日志与问题反馈

## 查看实时日志

日常、黎明界和公会战都使用功能页面底部的实时日志栏。展开后可以看到本次运行的步骤、结果与停止原因。每行可以选中复制；向上滚动查看旧记录后，点击“到底部”恢复自动滚动。

面板显示最近 500 行。“清空”只清理面板，不删除文件，也不修改任务状态。

任务结束后，程序先释放执行资源，再允许切换功能。清理期间会显示进度。如果提示退出尚未确认，请保留记录并重启 Maa-PCR；不要通过清账或重放未知操作解决。

## 导出本次日志

点击“导出本次日志”，预览并勾选要分享的截图，再选择 ZIP 保存位置。日常、黎明界和公会战分开保存，导出时使用当前功能最近一次连接或任务的记录。新记录会标明运行时的软件版本、开始时间、记录来源和结束结果。

连接失败、超时或取消后，即使还没开始任务，也能点击“导出本次日志”或“反馈问题”。日志会说明停在连接设备、获取首帧还是显示首帧，并附上可读取的本次连接底层日志。重新连接或开始任务会生成新记录，需要反馈时请先导出。

每个功能的用户日志缓存和导出 ZIP 分别最多 16 MiB。程序保留近期文字、底层运行片段和少量截图，空间不足时清理旧记录。

黎明界优先保留能关联到本次故障的识别原帧。任务失败时，如果只剩标题页或登录页，程序会尝试附上本次最后一张已经确认的业务场景，日志会标明它是较早的画面。登录、验证码和玩家资料页面不会自动附图。没有可用图片时，日志会说明原因。

这个限制不代表整个程序的磁盘占用。业务账本、未决记录、旧开发证据、原始调试资料和你已经另存的 ZIP 不参与这次轮换。

日志包采用固定文件清单，不打包账号凭据和原始业务账本。游戏截图仍可能含昵称或玩家 ID，请预览并取消不希望分享的图片。

## 反馈问题

点击“反馈问题”或“导出本次日志”都能打开反馈窗口。你可以选填触发前的操作、屏幕上看到的情况、预期结果和是否重复出现。说明保存在 ZIP 内的 `feedback.txt`。连接问题可以补充模拟器和 Android 版本。黎明界卡在选角时，可以注明游戏内的角色加入动画是否开启。

- **GitHub**　点击“打开 GitHub 反馈页”，保存 ZIP 后会打开带运行编号的网页。登录 GitHub，把 ZIP 拖进正文，再提交。公开仓库中的附件也会公开，请先检查说明和截图。
- **邮件**　反馈邮箱为 a877236828@gmail.com。点击“写反馈邮件”，保存 ZIP 后会打开已填好收件人和运行编号的草稿。添加 ZIP 后发送。

浏览器或邮件客户端无法打开时，可以使用“复制反馈说明”“复制反馈邮箱”和“打开日志包位置”。你可以使用任意邮箱发送反馈，不需要 GitHub 账号。

保存后，窗口会显示 ZIP 实际包含的截图数。上传附件或发送邮件由你确认。软件更新失败时，错误窗口会显示失败步骤和更新记录所在位置，可以用它们说明更新卡在哪一步。

## 启动设置

单功能的启动设置继续保留。选择带参数的 Windows 快捷方式时，程序会保留快捷方式的启动参数及工作目录。“附加命令”非空时优先使用你填写的命令，否则使用快捷方式参数。

当前 PCR 模式隐藏了无效的跨功能批量启动区域。你仍可以运行日常，等资源释放后手动切换到黎明界或公会战。
