# R53 入口识别修复与检查范围

## 修复内容

用户反馈的主页画面中，旧任务标签裁剪把“任务”稳定读成“住务”。主页守卫已经通过，任务按钮没有发送点击，最终在 30 秒期限后停止。使用同一套 OCRv4 权重，收紧完整文字裁剪后正确读到“任务”，置信度约 0.989。保留完整文字匹配和 0.8 阈值，不接受错字替换。

任务入口同时绑定默认主页布局。历史偏移主页中任务文字受到主菜单覆盖，没有完整可读正例；这类画面继续拒绝任务入口。礼物入口按默认和偏移布局分别组合完整文字与同布局的三个主页锚点，保留原 0.85 阈值和当前帧主页守卫，点击位置取实际识别框。

日程查看、GUI 一键日程和旧 CLI 日程使用固定的默认布局坐标或资源裁剪。现在显式要求默认布局，避免其他布局通过通用主页守卫后使用旧坐标。没有新增偏移布局日程支持。冒险入口的既定位置、所有输入次数和等待期限保持。

模型、金额、次数、账号身份、消费前新帧、结算、Stop 和 unknown 不重发规则保持。此修复不解释或清除旧未知记录，也不重放已经完成的任务。

## 入口检查清单

`scripts/entry_recognition_audit.py` 读取全部资源文件，展开既有动态 pipeline 工厂，并列出 Python 识别构造和派发位置。每条静态输入记录包含完整识别依赖、文字范围、阈值、目标和次数。它只报告规则和调用位置，不自动把某个入口标为原图验证通过。

本轮清单有 138 个静态输入节点、40 条动态工厂输入记录、36 个展开工厂、146 个 Python 构造位置和 183 个派发位置。动态记录包含不同工厂间的重复节点，不是 40 个独立功能。

| 范围 | 检查内容 | 离线证据与限制 |
|---|---|---|
| 主页、任务、礼物 | 完整文字、同布局组合、遮挡、就绪锚点、当前动作帧 | 原失败帧、历史原图和人工变体；公开测试仅保存去除账号内容的 UI 区域 |
| 日程查看、GUI 一键、CLI 日程、公会之家 | 固定坐标布局、页面身份、一次输入和读回 | 默认布局限制新增；偏移布局不放行日程，不声称已支持 |
| 主线预设、活动、深渊 | 主页到冒险、模块入口、页面标题、活动身份、列表与返回 | 保留原有独立规则和模块合同；未把不相关 OCR 统一降阈值 |
| 扫荡确认、结果、弹窗 | 数字和身份组合、确认资格、后继与未知停止 | 原业务验证保持，继续运行受影响合同；缺精确旧原图的项目单列 |
| 黎明界静态及动态导航 | 标题、公告、简介、入口、队伍、地图、奖励和返回 | 工厂、构造与调用位置全部列出；依赖运行参数的头像、金额等由原业务合同验证 |

所有静态输入节点都具有视觉或 Custom 守卫，静态识别依赖没有未解析引用或识别循环。固定 OCR 范围均位于 1280×720 资源坐标内。历史 `PresetsReached` 使用 Maa 默认阈值，并与返回按钮等守卫组合；本轮没有未经原图对照统一改动它。

## 新增离线检查

公开回归覆盖整条入口识别、一次模拟点击、动作前画面变化、空白、主页缺字、EXP 缺失、任务半字、错误标签、默认与偏移布局、布局混用，以及不依赖模块 Custom 注册的全部静态输入规则在空白画面上的拒绝。

历史语料对照包含 140 张保留原图与人工变体，另加用户原失败帧，共 141 张；对七条完整主页入口执行 987 次识别。任务入口正例从 20 到 25，礼物从 25 到 38，原成功没有倒退；主页守卫拒绝的画面仍不放行这些入口。重复历史帧、人工变体和校准原图相互关联，不是独立盲测成功率。

零设备输入回放使用官方 Maa 与 OCRv4。保存帧控制器的点击只记录到测试内存，不访问 ADB、模拟器或游戏。规则枚举、模拟业务合同、真实保存帧识别和设备验收分别记录；测试通过不能推出未来所有画面均可识别。

未验证真实游戏、自然整轮执行或真实升级。保数据更新、故障回滚和私态保留只在工程内的独立程序副本及合成数据中验收，最终结果以匹配清单的交付回执为准。
