# Maa PCR R33 / GUI 2.16.6（2026-10-06）

R33 从冻结 R32 匹配源码独立构建，包含原生停止等待有界、明确未发送的当前意图记录、更新器进程归属回退查询及识别回调 traceback 修复。家园同类路径补齐；一键日程只记录当前动作证据，保留复合事务未决。缺失或部分证明、消费后的结果/收尾失败仍保持未知，不自动重发，不清旧账。

GUI、Maa/Python/.NET/VC 运行库和 Pipeline 资源与 R32 字节一致；不包含黎明界在途草稿。GUI 组件号仍为 2.16.6，业务修订为 R33，两个编号含义不同。

本批业务离线检查已经通过，7 项历史私有原图回放因公开源码不提供素材而跳过。包内置 Python 的资源、实际合成 SavedImages 未发送证明、有界停止及 callback traceback 烟测通过。没有新游戏输入、真实安装升级或完整 GUI 整链实机验证。借用 Context 同步原生调用不能强制中断。

新安装：解压外层完整包，再解压其中 Maa-PCR-r33-player.zip 至自己的普通目录，使用该目录原有启动入口。请勿直接从压缩软件运行。

R32 保留数据升级：本补丁只匹配正式冻结 R32。退出原 Maa PCR/Agent，保持原目录和设置账本；不要直接解压覆盖。正常旧入口可导入 Maa-PCR-r32-to-r33.patch.zip，但旧入口首次仍运行 R32 维护器。

如果旧入口受到无关进程检查问题影响，先解压本包附带的 Maa-PCR-r33-source.zip，然后用原 R32 自带 Python 调用 R33 匹配源码内的正式维护器：

```powershell
& "<原R32安装目录>/runtime/python/python.exe" -X utf8 -B "<R33匹配源码目录>/scripts/player-maintenance.py" update --player "<原R32安装目录>" --archive "<Maa-PCR-r32-to-r33.patch.zip路径>"
```

该命令使用修复后的 R33 源码，仍核验精确基线、目标程序退出、文件哈希、私态保护和回滚；两种进程路径查询都不可用时仍拒绝。内置 Python 和原生 DLL 未发生变化。主程序本窗口不会自动安装或重启。

R30/R31 及更早安装不能强导本补丁，须先使用其匹配补丁到 R32，或另行新安装完整 R33。后续开发从正式 R33 的公开清单或匹配源码另建目录，默认 R33→下一修订；冻结 R32 和 R33 发布资料保持不改。完整与增量包的匹配源码、许可和本说明一并提供，私人截图、设置、日志和账本不公开。
