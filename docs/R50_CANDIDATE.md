# R50 候选：拖动动画与运行提速

## 本轮改动

日常模块拖动时，原项跟随鼠标，相邻项平滑让位。预览不写配置，有效松手后只提交一次顺序。取消、失去指针捕获、列表滚动、布局变化、隐藏、禁用和任务开始都会恢复视觉。Windows 关闭客户端动画时，保留插入位置提示，取消平滑运动。

普通、困难、高难、深域和活动复用扫荡结果链，深渊使用对应入口。在已提交扫荡后的结果等待阶段，可选识别“跳过完毕”。命中后最多点击一次，无按钮时沿正常结果流程继续。GUI 和 CLI 的玛那、经验探索也有独立跳过分支。日程地下城沿用已有处理。

跳过不会代替结果确认、余次核对或结算。列表读取保留目标次数、逐关报价和相邻页完整性检查。列表滑动仍为 1000 ms；部分固定 500 ms 等待改为局部画面稳定检测。未经实机标定，不采用更短滑动手势。

黎明界奖励页复用同帧“剩余次数”识别结果。地图目标识别按规则短路，保留全部场景与弹层判断；页面改变时，重新完整读取该帧的场景信息。点击、滚动或切页后仍使用新帧，不把旧结果当作当前输入资格。

## 计量与离线对照

日常报告增加原生截图、识别、输入、滑动和页面等待统计。黎明界增加协议请求及业务阶段计时。未采集的指标为 `null`；实际采集且没有事件的类别记为零。页面等待包含截图、识别和输入，滑动属于输入的一部分，这些嵌套耗时不能相加作为总耗时。

日常纯计量不安装或修改安全输入证据。结果未知、未发送、停止及账本判断仍使用原有证据规则。计量不增加截图或协议请求，不记录凭据、请求内容和账号信息。

`scripts/benchmark_r50.py` 在两个隔离子进程中加载 R49 和候选源码。公开合成案例各预热 5 次，再交替采样 20 对，记录完整结果、调用数、中位耗时和较慢样本。该工具测量 Python 回调，真实 OCR 耗时保持缺失，不能代替实机测试。

另有官方 Maa 的原生离线对照：同一合成地图帧，实际执行 OCR 和模板计算，各预热 2 次、交替采样 5 对。该结果只覆盖场景识别，不覆盖节点像素检测、设备截图、游戏动画或整局时间。完整测速记录随候选交付。

## 使用与验证边界

候选版本由独立构建参数标识为 R50；正式 R49 的版本默认值和验收文件保持。匹配源码中的 `delivery/acceptance.json` 是 R49 历史记录，不能用于晋级此候选。候选仍为 `release_staging`，没有公开发布或覆盖现用安装。

新增跳过锚点使用原始活动扫荡动画帧标定。其他共享结果入口的代码及合成回放已纳入检查，但不代表各模块的当前游戏画面已经实机验收。新增按钮有任何锚点不匹配时，继续沿正常结果等待，不盲点固定位置。

本轮保留每日目标、消耗核验、操作回执和结果未知不重发保护。未切换截图后端，未新增速度模式或模块。实机完整日常、黎明界整局速度及缩短手势仍待正常获准运行验证，不预先承诺整体提速比例。
