# r29 玩家反馈修复与模块衔接

本版继承 r28 的已确认消费结果检查点与安全收尾。

- 所有 GUI 选集模块共用当前 Owner 目标资格。普通本机 ADB 深渊入口复用日程已有目标，避免误要求 MuMu 身份；其他模块保持同一 Owner。该目标仅表示当前选中的 serial/package，不声明游戏账号或跨重启模拟器克隆连续性。
- 活动进入识别“获得活动登录奖励”标题、第N天奖励说明、专属关闭和明亮面板，关闭最多一次后复核活动入口。其他同名关闭、遮罩/未知弹窗和关闭失败仍停。
- 日程可从明确冒险页专属返回主页，再核主页进入日程；回执白名单同步，不把导航当消费，不重复一键。
- 普通预设后进入活动时，活动次数 OCR 使用自身声明的默认布局，作用域结束完整恢复原节点。活动导航的非消费预算按新 Port 作用域重置，失败 Port 不再次派发。

保持原有设置、顺序、日志、全部账本和引用证据。旧 unknown 不清除，不按新的 Start/设备分账绕过。CLI 与维护仍保留原稳定身份契约，停止撤权、设备/结果漂移、活动周期与报价未知仍截断后续。

验证范围包括私有原图官方 CustomController、业务/编排/故障测试、共享 Context、正式 TCP Agent、GUI Headless Start/Owner 与全部模块路由，以及正式补丁导入保留数据。GUI 使用保存帧和明确合成的业务端口，不能替代玩家雷电或其他设备的实机完整链验收。本轮无真实 ADB 发现、游戏输入或新消费；daily_complete 保持 false。具体评估结论和补丁校验见随补丁交付的验收说明。
