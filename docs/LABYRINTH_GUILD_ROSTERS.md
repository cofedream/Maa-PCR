# 黎明界开局候选：公会成员预置名单

GUI 的「各公会开局三人候选」按公会内嵌展示：第一行是公会名和三个槽位，下一行是该公会可选角色（头像+名称），已选角色高亮并标注槽位号；点角色加入空槽位，再点一次移除。
本文件记录预置名单的来源与内容；实际数据在 `gui/MFAAvalonia/MFAAvalonia/Pcr/labyrinth-guilds.json`（GUI 内嵌资源，按人物分组，`units` 为角色图鉴 ID）。

## 来源

- 2026-10-17 游戏内「角色选择」截图，按顺序对应：美食殿堂、破晓之星、咲恋救济院、王宫骑士团、拉比林斯。
- 截图中的卡片名与头像用 `assets/labyrinth/character-pack` 的图鉴/头像逐个核对；顺序为游戏里的显示顺序。
- 名单共 69 个图鉴单位；未出现的形态（公主系列、霸瞳天星、阿斯特赖亚、真龙、新年静流/璃乃等）没有列入。
- 角色 ID、名称、别名、头像仍来自 `assets/labyrinth/character-pack/characters.landosolroster.json` 与 `icons.json`，不复制数据。
- 选择器逻辑：`gui/MFAAvalonia/MFAAvalonia/Pcr/PcrLabyrinthCharacters.cs`、`PcrLabyrinthRoster.cs`、`PcrLabyrinthSettings.cs`。
- 保存格式不变：`opening_rosters` 仍是 `公会 → 三个槽位 → 每槽角色 ID 列表`；三个槽位都留空 = 沿用上游默认（`src/pcr_maa/labyrinth/opening.py` 的 defaults）。旧配置里同一槽位的多候选优先级仍会按原顺序读取，可在界面上逐个点掉。

## 调整方式

- 名单变化时只改 `labyrinth-guilds.json` 的人物与 `units`（名称/头像自动来自图鉴）。
- `PcrLabyrinthCredentials.Tests` 会校验各公会数量（18/15/15/12/9）、ID 唯一、所有单位都有头像文件，并逐项核对美食殿堂的完整顺序；调整名单后同步更新测试里的数量/顺序断言。
- 需要加入未出现的形态时，在对应 `persons` 的 `units` 里补图鉴 ID 即可（选择器只显示这里的名单）。

## Python 端识别：名单限定 + 一对一分配（2026-10-18）

开局「角色选择」页里同一角色 ID 只会出现一张卡（不同变种是不同图鉴 ID）。利用这点：

- GUI 在每次保存/开始时的 strategy 快照里附带 `guild_units`（5 个公会的完整角色 ID
  名单，来自内嵌 `labyrinth-guilds.json`）；图鉴加载失败时省略该字段，旧配置/旧 GUI
  仍按原路径识别。
- Python `MaaOpening.invite` 读取该公会的 `guild_units`，作为 `expected_roster` 传给
  `read` / `CharacterNavigation` / `ToggleOnce` / `InviteOnce`。
- `CharacterRecognizer` 在 opening 页对每张卡与每个名单 ID（取该 ID 所有 variant 的
  最高分）构建矩阵，用匈牙利算法求**一对一最大分配**；名单外的 ID（例如 1053 莫妮卡
  不在拉比林斯名单）不再参与竞争。分配后仍套原 `confidence>=.35` 与
  `rival_margin>=.045` 门槛，低分或冲突卡保持未知；现有“重复 ID 清空为未知”保留为兜底。
- 实测拉比林斯 720p 实拍 4 帧：9/9，1129 璃乃（仙境）由“与 1053 差 .0016 → 未知”
  变为 margin ≈ .55 的确定身份。
- 分配后还有第二次“排除”判定：首轮仍按原 `.35` 置信度 / `.045` 次优差门槛；对仍未确认
  的卡，把已被 trusted 卡占用的 ID 从次优池移除后重新计算次优差（每轮用轮初的 trusted
  快照，逐轮迭代到不动点），仍要求 `confidence>=.35` 且 `margin>=.045`。它只解决“次优
  ID 其实已被另一张已确认卡占走”的情况；低分卡与名单外卡不会被强配。
- 实测美食殿堂 720p 实拍 4 帧：第 13 张 1118 佩可莉姆（新年）首轮局部差 .036/.027
  未过线；其余 17 张确认后，名单内已无未确认竞争者（只剩它自己的 1118），排除后
  margin=confidence≈.533/.538，18/18 确认（原局部差保留在 `local_rival_margin`）。
- 前提：排除法假设画面里的每张卡都是传入名单的成员；若名单过期（新增形态不在名单、
  或名单中某单位实际未出现）而画面里恰好只有一张未确认卡，它可能被强配成最后一个
  未占用的 ID，因此 .35 置信度门槛不能去掉；名单仍需随游戏版本维护。
- opening 页 mask 同步改为 `right + top_right`（不再用 `top_left/bottom_left`）：
  名字条与星级/属性徽章本来在采样带外，右上角“借用”图标被遮住；battle/boss 不变。
- 公开回归：`tests/test_labyrinth_roster_assignment.py`（分配正确性/名单限定/配置校验/
  分配后排除与置信度门槛）。
