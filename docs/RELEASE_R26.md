# Maa PCR r26 显示映射开关（GUI 2.16.5）

高级设置新增“多显示屏映射校验”，默认关闭，按当前配置保存。

关闭：使用默认显示屏的截图与输入，不解析物理 Viewport。仍核对所选本机 ADB、PCR 游戏前台与默认输入屏幕、画面比例、Owner 原生对象绑定及停止撤权。游戏位于非默认显示屏时会提示开启校验。

开启：核对逻辑显示屏、实际物理显示屏及输入屏幕的对应关系，避免多显示屏场景截图和点击落在不同屏幕；物理映射缺失、冲突或变化时停止。雷电等单屏模拟器通常保持关闭即可；多显示屏或专门屏幕选择场景才需要开启。这个开关只控制物理视口校验，不关闭其它运行保护。旧实验/配置文件确认入口继续严格校验。

验证：先用 r25 正式 GUI 复现“Active physical viewport missing, invalid or conflicting”；同版 r26 Core 的正式 Start→Owner→TCP Agent→官方 Maa CustomController 保存帧回放验证默认模式与开启模式。包含真实鼠标勾选、保存重开、Android 9/现代 Android 合成显示信息、非默认显示屏提示、错误游戏、停止与映射变化。Release 构建成功；测试为离线模拟，未在反馈玩家的雷电上实际验收。Python 业务与资源沿用 r25，未混入黎明界实验。

版本号改为读取实际 GUI 程序集，解决旧版横幅固定显示2.16.3而误判补丁状态的问题。

更新：完全退出软件，在原软件目录双击“导入补丁包.bat”，拖入匹配当前版本的 ZIP 后回车。r25 用 Maa-PCR-r25-to-r26.patch.zip；r24 可直接用 Maa-PCR-r24-to-r26.patch.zip；其它版本使用完整包建立新目录。软件内暂没有 ZIP 选择界面。补丁严格核对原清单，保留设置、顺序、日志、证据和原未决账本，不能直接解压补丁覆盖。

更新后从“高级设置”确认开关未勾选，再回到游戏主页开始。若曾手动保存为开启，则保留该选择。
